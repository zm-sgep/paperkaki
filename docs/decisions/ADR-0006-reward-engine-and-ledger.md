# ADR-0006: Deterministic Reward Engine and Append-Only Point Ledger

## Status
Accepted

## Decision
- reward calculation is deterministic and versioned;
- mastery is owned by mastery domain;
- point history is append-only;
- automated events are idempotent;
- repeated mastered easy work has sharply diminishing yield;
- parent approves real-world reward redemption;
- LLMs never decide point values.

## Consequence
Reward decisions remain testable, explainable and resistant to farming.
