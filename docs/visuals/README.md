# Concept visuals

These images are early concept sketches. They are not the design reference for navigation.

- `parent-dashboard-concept.png` shows ten sidebar items (Home, Children, Assessments, Papers, Practice, Results, Progress, Question Bank, School Info, Settings) and a multi-chart Home. Both are superseded by ADR-0007 (parent navigation is only Home, Prepare, Progress, Rewards) and ADR-0008 (Home shows one recommended next action).
- `child-mock-exam-flow.png` and `child-ipad-marking-flow.png` remain useful for the exam and marked-paper layouts. Where they differ from `docs/UX_SPEC.md`, the spec wins.
